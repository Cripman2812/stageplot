# StageForge User Guide

## Getting started

1. Open the app (web or installed PWA).
2. Tap **＋** to open the equipment library and place items on stage.
3. Switch between **2D** and **3D** views with the bottom tabs.
4. Drag objects in 2D; pinch to zoom; use toolbar for rotate / duplicate / delete.
5. Use **I/O** for input, output and monitor lists.
6. Use **Patch** to document cable runs.
7. Open **Rider** to review estimates and export PDF (print), CSV or JSON.
8. **More** for project info, stage size, templates, save/import.

## Offline

Projects are stored on the device. You can work without network. Export JSON for backup.

## Safety

All power, SPL and weight numbers are **estimates for planning**. They are not engineering certificates. Consult qualified professionals for real-world system design and safety.
